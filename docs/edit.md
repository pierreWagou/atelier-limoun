# Guide d'édition

Ce guide explique comment modifier le site de l'Atelier Limoun. Aucune compétence technique n'est nécessaire : tout se fait dans un navigateur web.

## Se connecter

1. Ouvrez [cms.atelier-limoun.fr](https://cms.atelier-limoun.fr) dans votre navigateur.
2. Connectez-vous avec l'adresse e-mail et le mot de passe qui vous ont été remis.

::: tip Besoin d'aide ?
Si vous avez oublié votre mot de passe ou rencontrez un problème de connexion, contactez Pierre.
:::

## La page d'accueil

La page d'accueil se modifie dans le menu **Home** (dans la barre latérale de gauche) :

- **Title** — le gros titre en haut de la page
- **Subtitle** — la phrase sous le titre
- **Hero Image** — la grande image d'ouverture
- **Intro** — le paragraphe de présentation (vous pouvez mettre du **gras** avec le bouton B)

Cliquez **Save** pour enregistrer, puis **Publish** pour mettre le site à jour.

## Ajouter un projet

Les projets (réalisations, créations) se gèrent dans le menu **Content** → **Projects**.

### 1. Créer

Cliquez **Create new entry**.

### 2. Remplir

- **title** — le nom du projet (ex : « Vase en grès émaillé »)
- **slug** — automatique à partir du titre, pas besoin d'y toucher
- **description** — une courte description qui apparaîtra sous le titre dans la liste
- **order** — un nombre qui classe les projets : plus le nombre est petit, plus le projet apparaît en premier
- **coverImage** — l'image principale du projet
- **gallery** — les photos supplémentaires (vous pouvez en ajouter plusieurs)

### 3. Ajouter des images

1. Cliquez sur le cadre d'image, puis **Select from the media library**.
2. Glissez vos photos dans la fenêtre (ou cliquez pour choisir un fichier).
3. Sélectionnez l'image voulue, puis confirmez.

::: tip Conseils photos
- Format paysage (horizontal) de préférence pour la couverture
- Des images nettes, d'au moins 1200 pixels de large
:::

### 4. Publier

Le projet est d'abord un **brouillon** (Draft) : il n'est pas visible sur le site.

Quand tout est prêt, cliquez **Publish**.

::: warning Attention
Tant que le bouton indique **Unpublish**, le projet est en ligne. S'il indique **Publish**, il est encore invisible.
:::

## Modifier une page

Les pages classiques (comme « À propos ») se gèrent dans **Content** → **Pages**. Le fonctionnement est le même que pour les projets :

- **title** et **slug** pour le nom
- **content** pour le texte de la page (barre d'outils de mise en forme en haut)
- **heroImage** pour l'image d'ouverture (facultatif)

Pensez à **Publish** après chaque modification importante.

## Le site se met à jour tout seul

Après chaque publication, le site public se reconstruit automatiquement en **une minute environ**. Rafraîchissez la page [atelier-limoun.fr](https://atelier-limoun.fr) pour voir le résultat.

Si après 5 minutes rien n'a changé, contactez Pierre.

## Résumé

| Je veux… | Je vais dans… | Je clique sur… |
| --- | --- | --- |
| Modifier l'accueil | **Home** | Save puis Publish |
| Ajouter un projet | **Content** → **Projects** → Create new entry | Publish |
| Cacher un projet | **Content** → **Projects** → le projet | Unpublish |
| Modifier une page | **Content** → **Pages** → la page | Save puis Publish |
